# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately through GitHub instead: go to the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply as soon as possible, and credit in the fix if you'd like it.

## What counts

For example:

- Ways to get the Anthropic API key or other server settings.
- Ways around the rate limit or the moderation that could run up API costs or produce abusive verses at scale.
- Anything that stores, logs or leaks what visitors type.
- Cross-site scripting or other ways to run code in a visitor's browser.

## Supported versions

Only the latest version on the `main` branch is supported.
